## 📖 Introduction (项目简介)

This is a full-stack SaaS dashboard application designed with a microservices-ready architecture. It serves as a practical implementation of **Go high-concurrency patterns** and **modern React engineering**.

**Core Features (MVP):**
- 🚀 **High Performance API**: Built with Gin framework, following **Uber Go Style Guide**.
- 📊 **Data Visualization**: Interactive charts using Recharts/Echarts.
- 🛡️ **Containerization**: Docker & Docker Compose support for one-click deployment.

## 🛠️ Tech Stack (技术栈)

| Layer | Technology | Reason for Choice |
| :--- | :--- | :--- |
| **Backend** | **Go + Gin** | High performance, lightweight threads (Goroutines). |
| **Frontend** | **React + TS** | Component-based UI, strong typing safety. |
| **Database** | **MySQL + GORM** | Robust ORM for complex queries. |
| **DevOps** | **Docker** | Consistency across development and production. |
